# Sample Guide (demo data)

This file is sample data written for the end-to-end test. It describes an imaginary tool.

## Installation

Install the tool with the package manager. The installer needs Node.js 22 or newer.

## Configuration

The server listens on port 8787 by default. Set the PORT environment variable to change the port number.

## Backups

Backups run every night at 02:00 and are kept for 14 days.
